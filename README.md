# 新生活支援アプリ（プロトタイプ）

## 含まれている機能
- 初回アンケート
- 回答内容からの基本設定・やること自動生成
- 引っ越し先物件の家賃・敷金・礼金などの登録
- 引っ越し費用の概算
- 家具・家電の目安価格からの費用計算
- 手続きの条件分岐
- 手続きを「ステップ」で確認
- 外部の公式サイトへのリンク
- やることリストの追加・完了・削除
- 引っ越し予定日を基準にしたスケジュール
- ブラウザのlocalStorageへの保存
- スマートフォン向けUI
- PWA用manifest

## 起動
`index.html` をブラウザで開いてください。

GitHub Pagesに置く場合は、3ファイル + manifest.json をリポジトリにアップロードしてください。

## 今後のDB化
現在はlocalStorageで動作します。
次の段階でSupabase等のDBへ移行すると、
- ユーザーアカウント
- アンケート回答
- 物件情報
- タスク
- 手続き完了状況
- 家電相場マスタ
をユーザーごとに保存できます。

また、家電相場は `appliances` 配列をDBのマスタテーブルに置き換える想定です。
